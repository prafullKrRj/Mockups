# ASO copywriting for screenshot headlines

Adapted from the copy formulas in [ParthJadhav/app-store-screenshots](https://github.com/ParthJadhav/app-store-screenshots) (MIT).

**Core principle: screenshots are advertisements, not documentation.** Each slide sells one idea — a feeling, an outcome,
or a killed pain point. If the headline just names the screen ("Settings screen"), rewrite it.

## Deck narrative (in order)

1. **Hero** — the single biggest promise of the app. Uses the strongest screenshot.
2. **Differentiator** — what this app does that others do not.
3. **Core feature(s)** — one feature per slide, framed as a benefit.
4. **Proof / depth** — power features, customisation, privacy, offline, integrations.
5. **Closer** — the emotional end state, or a summary of the promise.

Slides 1–3 must work alone (see `play-store-specs.md`).

## Headline rules

- 2–6 words, ≤ 32 characters is ideal, hard cap 44 characters.
- Lead with a verb or an outcome: "Track every rupee", "Sleep better tonight", "Never miss a bill".
- One `highlight` word or short phrase per headline — the word that carries the benefit. It must be a substring of the
  headline exactly as written.
- No trailing period unless the style is deliberately editorial. No exclamation marks.
- Avoid jargon from the codebase ("dashboard", "CRUD", "module"). Talk like the user.

## Subline rules

- Optional. 1 sentence, ≤ 70 characters. Adds the concrete "how" behind the headline.
- Never repeat the headline's words.

## Eyebrow rules

- Optional. 1–3 words, UPPERCASE in render. A category tag: "BUDGETS", "OFFLINE FIRST", "STEP 2".

## Formulas

| Slide role | Formula | Example |
|---|---|---|
| hero | [Outcome] + [scope] | "All your bills, one calm place" |
| differentiator | [Thing] without [pain] | "Budgets without spreadsheets" |
| feature | [Verb] [object] [qualifier] | "Scan receipts in a second" |
| proof | [Number/fact] + [benefit] | "100% offline. Zero tracking." (only if true) |
| closer | [Emotional end state] | "Finally, money feels simple" |

## Feature graphic copy

- App name (exact) + one tagline ≤ 40 characters. Nothing else except optional 2–3 short badges.
